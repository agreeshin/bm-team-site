# Ursa Major Tech

## Цель

Русскоязычный одностраничный сайт команды с акцентом на автоматизацию
бизнес-процессов с помощью ИИ. Первый результат доступен локально;
домен и размещение пользователь предоставит позднее.

## Согласовано

- Astro, TypeScript и CSS; статический контент и отдельный слой эффектов.
  Изначальный Three.js-слой заменён лёгким Canvas2D при переходе к звёздному фону.
- Тёмная визуальная концепция, адаптация для телефонов. По новой правке:
  единый прямоугольный звёздный фон первого экрана по референсу Stars Galaxy,
  сохранение цвета #071724; отдельное созвездие и все его подписи удалить.
- Четыре гражданских кейса: «Кратчайшее», Molt Boat, складской дрон, АгроТехФарм.
- Названия и изображения из презентации разрешены к публикации.
- «Кратчайшее» позиционируется как разработка Ursa Major Tech по подтверждению владельца.
- Только прямые контакты, без формы заявки, аналитики и отдельных страниц проектов.
- Следующая дизайн-итерация ориентируется на screensnap.pro: единый navy-фон
  с мягкими градиентами нашей палитры, отдельные карточки услуг, без
  разделительных линий; звёздный Hero сохраняется. Все четыре проекта
  идут одинаковыми вертикальными секциями, по одному изображению на проект.
- Заголовок и навигация: «Сделаем для Вас»; первые две услуги:
  «Автоматизируйте рутину. Масштабируйте прибыль» и «ИИ помощник ответит клиентам».
- ИП Гришин Анатолий Александрович; ОГРНИП 317665800027995;
  +79320112811; greeshin.anatoly@yandex.ru.
- Не публиковать военные проекты, неподтверждённые результаты и цифры;
  складской дрон сохраняет статус опытного образца, Molt Boat описывается

## Критерий Готовности

Страница собирается, открывается локально, содержит согласованные кейсы
и контакты, не имеет горизонтального переполнения на телефоне,
сохраняет основное содержание без JavaScript и анимации. Контент не зависит
от Canvas и выполнения эффектов. Проверены основные ссылки, меню и отсутствие ошибок загрузки.
